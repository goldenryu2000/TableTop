# Tabletop v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Tabletop Android app shell with a polished, fully playable Klondike Solitaire, buildable as a signed release APK.

**Architecture:** Multi-module Gradle project. Pure Kotlin/JVM modules hold the card model and the Klondike rules engine (immutable state, unit tested). Android library modules hold the design system, card rendering, sound/haptics, a small game API (registry entry, key-value store, stats) and the Klondike Compose UI. The `app` module wires services, navigation, home, settings and stats.

**Tech Stack:** Kotlin 2.2, Jetpack Compose (Material 3), Navigation Compose, DataStore Preferences, kotlinx.serialization, kotlinx.coroutines, JUnit 4, Robolectric, AGP 8.13, Gradle 8.14.

**Spec:** `docs/superpowers/specs/2026-10-07-tabletop-design.md`

## Global Constraints

- License GPL-3.0. No Google Play Services, no proprietary deps, no network permission.
- applicationId and base package `dev.tabletop`. minSdk 26, targetSdk 36, compileSdk 36.
- JDK 21 at `~/Android/jdk`, SDK at `~/Android/Sdk`. Every Gradle command runs with `JAVA_HOME=$HOME/Android/jdk`.
- Engine modules (`core/cards-model`, `games/klondike/engine`) have no Android dependencies.
- Code comments short, one line where possible. No em-dashes in code, comments, docs or commit messages.
- Commit messages plain, no AI attribution trailers.
- Card table palette: deep ink-green, calm minimal. Sounds soft and quiet.

## Review Focus

1. App backgrounded or killed mid-game: the game must resume exactly, including undo history. Pinned by a ViewModel test that `setVisible(false)` writes the save immediately and a resume test that keeps `canUndo`.
2. Corrupt or incompatible save JSON: must start a fresh game, never crash. Pinned by a ViewModel test with garbage in the save key.
3. Very tall tableau piles on short screens: all cards must stay on screen. Pinned by a layout test with a 19-card column.
4. Input during auto-finish: taps, drags, undo and new game must be ignored until it ends. Pinned by a ViewModel test.
5. Dropping a card back on its own pile or on empty table: snaps back silently, no "invalid" sound. Pinned by a ViewModel test.

```kotlin
package dev.tabletop.klondike.engine

import dev.tabletop.cards.Card
import dev.tabletop.cards.Rank
import dev.tabletop.cards.Suit
import org.junit.Assert.assertEquals
import org.junit.Assert.assertTrue

/** Parses "AS", "10H", "QD", "KC". */
fun c(code: String): Card {
    val suit = when (code.last()) {
        'S' -> Suit.SPADES; 'H' -> Suit.HEARTS; 'D' -> Suit.DIAMONDS; 'C' -> Suit.CLUBS
        else -> error("bad suit in $code")
    }
    val rank = Rank.entries.first { it.label == code.dropLast(1).replace("T", "10") }
    return Card(suit, rank)
}

fun up(code: String) = TableauCard(c(code), faceUp = true)
fun down(code: String) = TableauCard(c(code), faceUp = false)

/** A state with only the given piles; foundations given as top rank per suit (0 = empty). */
fun state(
    stock: List<String> = emptyList(),
    waste: List<String> = emptyList(),
    foundationTops: Map<Suit, Int> = emptyMap(),
    tableau: List<List<TableauCard>> = List(7) { emptyList() },
    drawMode: DrawMode = DrawMode.ONE,
    score: Int = 0,
) = GameState(
    seed = 0,
    drawMode = drawMode,
    stock = stock.map(::c),
    waste = waste.map(::c),
    foundations = Suit.entries.map { s -> Rank.entries.take(foundationTops[s] ?: 0).map { Card(s, it) } },
    tableau = tableau + List(7 - tableau.size) { emptyList() },
    score = score,
)

fun GameState.allCards() = stock + waste + foundations.flatten() + tableau.flatten().map { it.card }

/** Structural invariants that must hold for any state reachable from a deal. */
fun GameState.assertValid() {
    val all = allCards()
    assertEquals(52, all.size)
    assertEquals(52, all.toSet().size)
    foundations.forEachIndexed { i, pile ->
        pile.forEachIndexed { r, card ->
            assertEquals(Suit.entries[i], card.suit)
            assertEquals(r + 1, card.rank.value)
        }
    }
    tableau.forEach { pile ->
        if (pile.isNotEmpty()) {
            assertTrue("top must be face up", pile.last().faceUp)
            val firstUp = pile.indexOfFirst { it.faceUp }
            assertTrue("face-down above face-up", pile.drop(firstUp).all { it.faceUp })
        }
    }
}
```

```kotlin
package dev.tabletop.cards

import kotlinx.serialization.Serializable

@Serializable
enum class Suit(val symbol: String, val isRed: Boolean) {
    SPADES("♠", false), HEARTS("♥", true), DIAMONDS("♦", true), CLUBS("♣", false)
}

@Serializable
enum class Rank(val value: Int, val label: String) {
    ACE(1, "A"), TWO(2, "2"), THREE(3, "3"), FOUR(4, "4"), FIVE(5, "5"), SIX(6, "6"), SEVEN(7, "7"),
    EIGHT(8, "8"), NINE(9, "9"), TEN(10, "10"), JACK(11, "J"), QUEEN(12, "Q"), KING(13, "K")
}

@Serializable
data class Card(val suit: Suit, val rank: Rank) {
    val isRed: Boolean get() = suit.isRed

    override fun toString() = rank.label + suit.symbol

    companion object {
        val deck: List<Card> = Suit.entries.flatMap { s -> Rank.entries.map { Card(s, it) } }
    }
}
```

```kotlin
package dev.tabletop.klondike.engine

import dev.tabletop.cards.Card
import dev.tabletop.cards.Suit
import kotlinx.serialization.Serializable
import kotlin.random.Random

@Serializable
enum class DrawMode(val count: Int) { ONE(1), THREE(3) }

@Serializable
data class TableauCard(val card: Card, val faceUp: Boolean)

/** Full Klondike position. Every list is bottom-first, so `last()` is the top card. */
@Serializable
data class GameState(
    val seed: Long,
    val drawMode: DrawMode,
    val stock: List<Card>,
    val waste: List<Card>,
    val foundations: List<List<Card>>,
    val tableau: List<List<TableauCard>>,
    val score: Int = 0,
    val moves: Int = 0,
    val elapsedMs: Long = 0,
) {
    fun foundation(suit: Suit): List<Card> = foundations[suit.ordinal]

    val isWon: Boolean get() = foundations.all { it.size == 13 }

    companion object {
        fun deal(seed: Long, drawMode: DrawMode): GameState {
            val cards = Card.deck.shuffled(Random(seed))
            var next = 0
            val tableau = List(7) { pile ->
                List(pile + 1) { i -> TableauCard(cards[next++], faceUp = i == pile) }
            }
            return GameState(
                seed = seed,
                drawMode = drawMode,
                stock = cards.drop(next),
                waste = emptyList(),
                foundations = List(4) { emptyList() },
                tableau = tableau,
            )
        }
    }
}
```

```kotlin
package dev.tabletop.klondike.engine

import dev.tabletop.cards.Card
import dev.tabletop.cards.Rank

/** Windows-style standard scoring. */
object Scoring {
    const val WASTE_TO_TABLEAU = 5
    const val WASTE_TO_FOUNDATION = 10
    const val TABLEAU_TO_FOUNDATION = 10
    const val TURN_OVER = 5
    const val FOUNDATION_TO_TABLEAU = -15
    const val RECYCLE_DRAW_ONE = -100
    const val UNDO = -2
}

fun GameState.apply(move: Move): GameState? = when (move) {
    Move.Draw -> draw()
    is Move.Transfer -> transfer(move)
}

fun GameState.topCard(pile: Pile): Card? = when (pile) {
    Pile.Waste -> waste.lastOrNull()
    is Pile.Foundation -> foundation(pile.suit).lastOrNull()
    is Pile.Tableau -> tableau.getOrNull(pile.index)?.lastOrNull()?.card
}

/** Cards that would leave [from], bottom-first, or null if they cannot be picked up together. */
fun GameState.pickUp(from: Pile, count: Int): List<Card>? {
    if (count < 1) return null
    return when (from) {
        Pile.Waste, is Pile.Foundation -> topCard(from)?.takeIf { count == 1 }?.let(::listOf)
        is Pile.Tableau -> {
            val pile = tableau.getOrNull(from.index) ?: return null
            if (count > pile.size) return null
            val run = pile.takeLast(count)
            if (!run.all { it.faceUp }) return null
            val cards = run.map { it.card }
            cards.takeIf { it.zipWithNext().all { (below, above) -> stacks(above, onto = below) } }
        }
    }
}

fun GameState.accepts(to: Pile, cards: List<Card>): Boolean {
    val first = cards.firstOrNull() ?: return false
    return when (to) {
        Pile.Waste -> false
        is Pile.Foundation ->
            cards.size == 1 && first.suit == to.suit && first.rank.value == foundation(to.suit).size + 1
        is Pile.Tableau -> {
            val pile = tableau.getOrNull(to.index) ?: return false
            val top = pile.lastOrNull()
            if (top == null) first.rank == Rank.KING else top.faceUp && stacks(first, onto = top.card)
        }
    }
}

private fun stacks(card: Card, onto: Card) = card.isRed != onto.isRed && card.rank.value == onto.rank.value - 1

private fun GameState.draw(): GameState? = when {
    stock.isNotEmpty() -> {
        val n = minOf(drawMode.count, stock.size)
        copy(stock = stock.dropLast(n), waste = waste + stock.takeLast(n).reversed(), moves = moves + 1)
    }
    waste.isNotEmpty() -> {
        val penalty = if (drawMode == DrawMode.ONE) Scoring.RECYCLE_DRAW_ONE else 0
        copy(
            stock = waste.reversed(),
            waste = emptyList(),
            moves = moves + 1,
            score = (score + penalty).coerceAtLeast(0),
        )
    }
    else -> null
}

private fun GameState.transfer(m: Move.Transfer): GameState? {
    if (m.from == m.to) return null
    val cards = pickUp(m.from, m.count) ?: return null
    if (!accepts(m.to, cards)) return null

    var gained = transferScore(m.from, m.to)
    var next = when (val from = m.from) {
        Pile.Waste -> copy(waste = waste.dropLast(1))
        is Pile.Foundation -> copy(foundations = foundations.replace(from.suit.ordinal) { it.dropLast(1) })
        is Pile.Tableau -> {
            var remaining = tableau[from.index].dropLast(m.count)
            val newTop = remaining.lastOrNull()
            if (newTop != null && !newTop.faceUp) {
                remaining = remaining.dropLast(1) + newTop.copy(faceUp = true)
                gained += Scoring.TURN_OVER
            }
            copy(tableau = tableau.replace(from.index) { remaining })
        }
    }
    next = when (val to = m.to) {
        is Pile.Foundation -> next.copy(foundations = next.foundations.replace(to.suit.ordinal) { it + cards })
        is Pile.Tableau -> next.copy(tableau = next.tableau.replace(to.index) { it + cards.map { c -> TableauCard(c, true) } })
        Pile.Waste -> return null
    }
    return next.copy(moves = moves + 1, score = (score + gained).coerceAtLeast(0))
}

private fun transferScore(from: Pile, to: Pile): Int = when {
    from == Pile.Waste && to is Pile.Tableau -> Scoring.WASTE_TO_TABLEAU
    from == Pile.Waste && to is Pile.Foundation -> Scoring.WASTE_TO_FOUNDATION
    from is Pile.Tableau && to is Pile.Foundation -> Scoring.TABLEAU_TO_FOUNDATION
    from is Pile.Foundation && to is Pile.Tableau -> Scoring.FOUNDATION_TO_TABLEAU
    else -> 0
}

private inline fun <T> List<T>.replace(index: Int, f: (T) -> T): List<T> =
    mapIndexed { i, v -> if (i == index) f(v) else v }
```

```kotlin
package dev.tabletop.klondike.engine

import kotlinx.serialization.Serializable

/** A game in progress with its undo history. */
@Serializable
data class Session(val state: GameState, val history: List<GameState> = emptyList()) {
    val canUndo: Boolean get() = history.isNotEmpty()

    fun play(move: Move): Session? {
        val next = state.apply(move) ?: return null
        return Session(next, (history + state).takeLast(MAX_HISTORY))
    }

    /** Restores the previous position; time keeps running and the undo counts as a move. */
    fun undo(): Session? {
        val previous = history.lastOrNull() ?: return null
        val restored = previous.copy(
            elapsedMs = state.elapsedMs,
            moves = state.moves + 1,
            score = (previous.score + Scoring.UNDO).coerceAtLeast(0),
        )
        return Session(restored, history.dropLast(1))
    }

    fun tick(ms: Long): Session = copy(state = state.copy(elapsedMs = state.elapsedMs + ms))

    companion object {
        const val MAX_HISTORY = 500
    }
}
```

```kotlin
package dev.tabletop.klondike.engine

import dev.tabletop.cards.Rank

val GameState.canAutoComplete: Boolean
    get() = !isWon && stock.isEmpty() && waste.isEmpty() && tableau.all { pile -> pile.all { it.faceUp } }

/** Foundation moves that finish the game, lowest cards first. Empty unless [canAutoComplete]. */
fun GameState.autoCompleteMoves(): List<Move> {
    if (!canAutoComplete) return emptyList()
    val moves = mutableListOf<Move>()
    var s = this
    while (!s.isWon) {
        val step = s.tableau.indices
            .mapNotNull { i -> s.tableau[i].lastOrNull()?.let { i to it.card } }
            .sortedBy { (_, card) -> card.rank.value }
            .firstNotNullOfOrNull { (i, card) ->
                val m = Move.Transfer(Pile.Tableau(i), Pile.Foundation(card.suit))
                s.apply(m)?.let { m to it }
            } ?: return emptyList()
        moves += step.first
        s = step.second
    }
    return moves
}

/** Where a tap should send the top [count] cards of [from]: foundation first, then a non-empty column. */
fun GameState.bestMoveFor(from: Pile, count: Int = 1): Move.Transfer? {
    val cards = pickUp(from, count) ?: return null
    val targets = buildList {
        if (count == 1 && from !is Pile.Foundation) add(Pile.Foundation(cards.first().suit))
        tableau.indices.sortedBy { if (tableau[it].isEmpty()) 1 else 0 }.forEach { add(Pile.Tableau(it)) }
    }
    return targets.asSequence()
        .filter { it != from }
        .map { Move.Transfer(from, it, count) }
        .filterNot { isKingShuffle(it) }
        .firstOrNull { apply(it) != null }
}

/** A useful next move, or null when nothing is left to try. */
fun GameState.hint(): Move? {
    val sources = listOf(Pile.Waste) + tableau.indices.map { Pile.Tableau(it) }
    for (from in sources) {
        val card = topCard(from) ?: continue
        val m = Move.Transfer(from, Pile.Foundation(card.suit))
        if (apply(m) != null) return m
    }
    for (i in tableau.indices) {
        val pile = tableau[i]
        val firstUp = pile.indexOfFirst { it.faceUp }
        if (firstUp < 0 || (firstUp == 0 && pile[0].card.rank == Rank.KING)) continue
        val count = pile.size - firstUp
        for (j in tableau.indices) {
            if (j == i) continue
            val m = Move.Transfer(Pile.Tableau(i), Pile.Tableau(j), count)
            if (apply(m) != null) return m
        }
    }
    if (waste.isNotEmpty()) {
        for (j in tableau.indices) {
            val m = Move.Transfer(Pile.Waste, Pile.Tableau(j))
            if (apply(m) != null) return m
        }
    }
    return if (stock.isNotEmpty() || waste.isNotEmpty()) Move.Draw else null
}

/** Moving a whole column onto an empty column changes nothing. */
private fun GameState.isKingShuffle(m: Move.Transfer): Boolean {
    val from = m.from as? Pile.Tableau ?: return false
    val to = m.to as? Pile.Tableau ?: return false
    return tableau[to.index].isEmpty() && m.count == tableau[from.index].size
}
```

```python
#!/usr/bin/env python3
"""Synthesizes Tabletop's calm UI sounds into core/feedback res/raw. Stdlib only."""
import math, random, struct, wave
from pathlib import Path

RATE = 44100
OUT = Path(__file__).resolve().parent.parent / "core/feedback/src/main/res/raw"


def env(i, n, attack=0.004, power=3.0):
    t = i / RATE
    a = min(1.0, t / attack) if attack > 0 else 1.0
    return a * (1 - i / n) ** power


def noise(dur, cutoff=0.15, attack=0.004, power=3.0, seed=1):
    rnd = random.Random(seed)
    n = int(dur * RATE)
    out, y = [], 0.0
    for i in range(n):
        y += cutoff * (rnd.uniform(-1, 1) - y)  # one-pole low-pass
        out.append(y * env(i, n, attack, power))
    return out


def tone(freq, dur, attack=0.006, power=2.5, glide=0.0, harmonics=((1, 1.0),)):
    n = int(dur * RATE)
    out, phase = [], 0.0
    for i in range(n):
        f = freq * (1 + glide * i / n)
        phase += 2 * math.pi * f / RATE
        s = sum(a * math.sin(phase * h) for h, a in harmonics)
        out.append(s * env(i, n, attack, power))
    return out


def mix(*parts):
    """parts: (offset_seconds, samples, gain)."""
    length = max(int(o * RATE) + len(s) for o, s, _ in parts)
    out = [0.0] * length
    for o, s, g in parts:
        start = int(o * RATE)
        for i, v in enumerate(s):
            out[start + i] += v * g
    return out


def write(name, samples, peak=0.25):
    m = max(abs(v) for v in samples) or 1.0
    frames = b"".join(struct.pack("<h", int(v / m * peak * 32767)) for v in samples)
    with wave.open(str(OUT / f"{name}.wav"), "wb") as w:
        w.setnchannels(1)
        w.setsampwidth(2)
        w.setframerate(RATE)
        w.writeframes(frames)


def main():
    OUT.mkdir(parents=True, exist_ok=True)
    write("pickup", noise(0.06, cutoff=0.25, power=4), peak=0.12)
    write("place", mix((0, noise(0.05, cutoff=0.12, power=5, seed=2), 1.0),
                       (0, tone(170, 0.09, power=4), 0.6)), peak=0.22)
    write("flip", noise(0.09, cutoff=0.35, attack=0.03, power=2, seed=3), peak=0.12)
    write("draw", noise(0.07, cutoff=0.3, attack=0.02, power=2.5, seed=4), peak=0.11)
    write("foundation", mix((0, tone(880, 0.45, harmonics=((1, 1.0), (2, 0.15))), 1.0),
                            (0.03, tone(1318.5, 0.4), 0.45)), peak=0.16)
    write("invalid", tone(230, 0.14, glide=-0.2, power=3, harmonics=((1, 1.0), (2, 0.2))), peak=0.14)
    write("deal", mix(*[(k * 0.055, noise(0.05, cutoff=0.3, power=3, seed=10 + k), 1.0) for k in range(7)]), peak=0.1)
    notes = [523.25, 659.25, 783.99, 1046.5]
    write("win", mix(*[(k * 0.14, tone(f, 0.9, harmonics=((1, 1.0), (2, 0.12))), 1.0) for k, f in enumerate(notes)]), peak=0.18)


if __name__ == "__main__":
    main()
```

```kotlin
package dev.tabletop.feedback

import android.content.Context
import android.media.AudioAttributes
import android.media.SoundPool
import android.os.Build
import android.os.VibrationEffect
import android.os.Vibrator
import android.os.VibratorManager

enum class FeedbackEvent { Pickup, Place, Flip, Draw, Foundation, Invalid, Deal, Win }

interface Feedback {
    fun play(event: FeedbackEvent)
}

object NoFeedback : Feedback {
    override fun play(event: FeedbackEvent) = Unit
}

/** Plays short calm sounds through SoundPool and light haptics through the vibrator. */
class AndroidFeedback(context: Context) : Feedback {
    var soundEnabled = true
    var hapticsEnabled = true

    private val pool = SoundPool.Builder()
        .setMaxStreams(4)
        .setAudioAttributes(
            AudioAttributes.Builder()
                .setUsage(AudioAttributes.USAGE_GAME)
                .setContentType(AudioAttributes.CONTENT_TYPE_SONIFICATION)
                .build(),
        )
        .build()

    private val sounds: Map<FeedbackEvent, Int> = mapOf(
        FeedbackEvent.Pickup to R.raw.pickup,
        FeedbackEvent.Place to R.raw.place,
        FeedbackEvent.Flip to R.raw.flip,
        FeedbackEvent.Draw to R.raw.draw,
        FeedbackEvent.Foundation to R.raw.foundation,
        FeedbackEvent.Invalid to R.raw.invalid,
        FeedbackEvent.Deal to R.raw.deal,
        FeedbackEvent.Win to R.raw.win,
    ).mapValues { (_, res) -> pool.load(context, res, 1) }

    private val vibrator: Vibrator? = if (Build.VERSION.SDK_INT >= 31) {
        context.getSystemService(VibratorManager::class.java)?.defaultVibrator
    } else {
        @Suppress("DEPRECATION")
        context.getSystemService(Vibrator::class.java)
    }

    override fun play(event: FeedbackEvent) {
        if (soundEnabled) sounds[event]?.let { pool.play(it, 0.7f, 0.7f, 1, 0, 1f) }
        if (hapticsEnabled) vibrate(event)
    }

    private fun vibrate(event: FeedbackEvent) {
        val v = vibrator?.takeIf { it.hasVibrator() } ?: return
        val effect = if (Build.VERSION.SDK_INT >= 29) {
            when (event) {
                FeedbackEvent.Pickup, FeedbackEvent.Draw -> VibrationEffect.EFFECT_TICK
                FeedbackEvent.Place, FeedbackEvent.Foundation -> VibrationEffect.EFFECT_CLICK
                FeedbackEvent.Invalid -> VibrationEffect.EFFECT_DOUBLE_CLICK
                FeedbackEvent.Win -> VibrationEffect.EFFECT_HEAVY_CLICK
                FeedbackEvent.Flip, FeedbackEvent.Deal -> return
            }.let(VibrationEffect::createPredefined)
        } else {
            val ms = when (event) {
                FeedbackEvent.Pickup, FeedbackEvent.Draw -> 8L
                FeedbackEvent.Place, FeedbackEvent.Foundation -> 14L
                FeedbackEvent.Invalid -> 30L
                FeedbackEvent.Win -> 40L
                FeedbackEvent.Flip, FeedbackEvent.Deal -> return
            }
            VibrationEffect.createOneShot(ms, VibrationEffect.DEFAULT_AMPLITUDE)
        }
        v.vibrate(effect)
    }
}
```

```kotlin
package dev.tabletop.game

import androidx.datastore.core.DataStore
import androidx.datastore.preferences.core.Preferences
import androidx.datastore.preferences.core.edit
import androidx.datastore.preferences.core.emptyPreferences
import androidx.datastore.preferences.core.stringPreferencesKey
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.catch
import kotlinx.coroutines.flow.distinctUntilChanged
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.flow.map
import kotlinx.coroutines.flow.update
import kotlinx.serialization.json.Json

/** String values by key; games store JSON documents here. */
interface KeyValueStore {
    fun observe(key: String): Flow<String?>
    suspend fun write(key: String, value: String?)
}

class DataStoreKeyValueStore(private val dataStore: DataStore<Preferences>) : KeyValueStore {
    override fun observe(key: String): Flow<String?> = dataStore.data
        .catch { emit(emptyPreferences()) }
        .map { it[stringPreferencesKey(key)] }
        .distinctUntilChanged()

    override suspend fun write(key: String, value: String?) {
        dataStore.edit { prefs ->
            val k = stringPreferencesKey(key)
            if (value == null) prefs.remove(k) else prefs[k] = value
        }
    }
}

class InMemoryKeyValueStore(initial: Map<String, String> = emptyMap()) : KeyValueStore {
    private val values = MutableStateFlow(initial)

    override fun observe(key: String): Flow<String?> = values.map { it[key] }.distinctUntilChanged()

    override suspend fun write(key: String, value: String?) {
        values.update { if (value == null) it - key else it + (key to value) }
    }
}

val TabletopJson = Json {
    ignoreUnknownKeys = true
    encodeDefaults = true
}

inline fun <reified T> KeyValueStore.observeJson(key: String, default: T): Flow<T> = observe(key).map { raw ->
    raw?.let { runCatching { TabletopJson.decodeFromString<T>(it) }.getOrNull() } ?: default
}

suspend inline fun <reified T> KeyValueStore.readJson(key: String, default: T): T = observeJson(key, default).first()

suspend inline fun <reified T> KeyValueStore.writeJson(key: String, value: T?) {
    write(key, value?.let { TabletopJson.encodeToString(it) })
}
```

`GameStats.kt`:

```kotlin
package dev.tabletop.game

import kotlinx.coroutines.flow.Flow
import kotlinx.serialization.Serializable

@Serializable
data class GameStats(
    val played: Int = 0,
    val won: Int = 0,
    val bestTimeMs: Long? = null,
    val bestScore: Int? = null,
    val currentStreak: Int = 0,
    val bestStreak: Int = 0,
) {
    val winRate: Float get() = if (played == 0) 0f else won.toFloat() / played

    fun recordStart() = copy(played = played + 1)

    fun recordWin(timeMs: Long, score: Int): GameStats {
        val streak = currentStreak + 1
        return copy(
            won = won + 1,
            bestTimeMs = minOf(bestTimeMs ?: timeMs, timeMs),
            bestScore = maxOf(bestScore ?: score, score),
            currentStreak = streak,
            bestStreak = maxOf(bestStreak, streak),
        )
    }

    fun recordAbandon() = copy(currentStreak = 0)
}

class StatsRepository(private val store: KeyValueStore) {
    fun observe(gameId: String): Flow<GameStats> = store.observeJson(key(gameId), GameStats())

    suspend fun update(gameId: String, f: (GameStats) -> GameStats) {
        store.writeJson(key(gameId), f(store.readJson(key(gameId), GameStats())))
    }

    suspend fun reset(gameId: String) = store.write(key(gameId), null)

    private fun key(gameId: String) = "stats_$gameId"
}
```

```kotlin
package dev.tabletop.klondike.ui

import androidx.compose.ui.geometry.Offset
import androidx.compose.ui.geometry.Rect
import androidx.compose.ui.geometry.Size
import dev.tabletop.cards.Card
import dev.tabletop.cards.Suit
import dev.tabletop.cards.ui.CARD_ASPECT
import dev.tabletop.klondike.engine.DrawMode
import dev.tabletop.klondike.engine.GameState
import dev.tabletop.klondike.engine.Pile

/** Where one card sits. [pile] is null for the stock. */
data class CardPlacement(
    val card: Card,
    val faceUp: Boolean,
    val pile: Pile?,
    val index: Int,
    val topLeft: Offset,
    val z: Int,
)

class TableLayout(
    val cardSize: Size,
    val stock: Rect,
    val piles: Map<Pile, Rect>,
    val cards: List<CardPlacement>,
) {
    private val byCard = cards.associateBy { it.card }

    fun placementOf(card: Card): CardPlacement? = byCard[card]

    fun cardAt(point: Offset): CardPlacement? =
        cards.filter { Rect(it.topLeft, cardSize).contains(point) }.maxByOrNull { it.z }

    /** Piles the dragged card overlaps, biggest overlap first. Tableau areas span the full column. */
    fun dropCandidates(dragged: Rect): List<Pile> = piles
        .filterKeys { it != Pile.Waste }
        .mapNotNull { (pile, area) ->
            val i = area.intersect(dragged)
            if (i.width > 0f && i.height > 0f) pile to i.width * i.height else null
        }
        .sortedByDescending { it.second }
        .map { it.first }
}

fun computeLayout(state: GameState, width: Float, height: Float, gap: Float, leftHanded: Boolean): TableLayout {
    val cardW = (width - gap * 8) / 7
    val cardH = cardW / CARD_ASPECT
    val size = Size(cardW, cardH)
    fun x(column: Int): Float {
        val left = gap + column * (cardW + gap)
        return if (leftHanded) width - left - cardW else left
    }
    val top = gap

    val stock = Rect(Offset(x(0), top), size)
    val piles = mutableMapOf<Pile, Rect>(Pile.Waste to Rect(Offset(x(1), top), size))
    Suit.entries.forEachIndexed { i, s -> piles[Pile.Foundation(s)] = Rect(Offset(x(3 + i), top), size) }

    val cards = mutableListOf<CardPlacement>()
    var z = 0
    state.stock.forEachIndexed { i, c -> cards += CardPlacement(c, false, null, i, stock.topLeft, z++) }

    val fanStep = cardW * 0.34f * if (leftHanded) -1 else 1
    val visible = minOf(if (state.drawMode == DrawMode.THREE) 3 else 1, state.waste.size)
    state.waste.forEachIndexed { i, c ->
        val fromTop = state.waste.size - 1 - i
        val slot = if (fromTop >= visible) 0 else visible - 1 - fromTop
        cards += CardPlacement(c, true, Pile.Waste, i, Offset(x(1) + slot * fanStep, top), z++)
    }

    Suit.entries.forEach { s ->
        val at = piles.getValue(Pile.Foundation(s)).topLeft
        state.foundation(s).forEachIndexed { i, c -> cards += CardPlacement(c, true, Pile.Foundation(s), i, at, z++) }
    }

    val tableauTop = top + cardH + gap * 2.5f
    val available = height - tableauTop - gap
    val downStep = cardH * 0.12f
    val upStep = cardH * 0.27f
    state.tableau.forEachIndexed { p, pile ->
        val natural = pile.dropLast(1).sumOf { (if (it.faceUp) upStep else downStep).toDouble() }.toFloat()
        val scale = if (natural > 0f && natural + cardH > available) ((available - cardH) / natural).coerceIn(0.05f, 1f) else 1f
        var y = tableauTop
        pile.forEachIndexed { i, tc ->
            cards += CardPlacement(tc.card, tc.faceUp, Pile.Tableau(p), i, Offset(x(p), y), z++)
            y += (if (tc.faceUp) upStep else downStep) * scale
        }
        piles[Pile.Tableau(p)] = Rect(x(p) - gap / 2, tableauTop, x(p) + cardW + gap / 2, height)
    }

    return TableLayout(size, stock, piles, cards)
}
```

```kotlin
const val KLONDIKE_ID = "klondike"
const val KLONDIKE_SETTINGS_KEY = "klondike_settings"
const val SAVE_DEBOUNCE_MS = 300L
private const val AUTO_FINISH_STEP_MS = 90L

@Serializable
data class KlondikeSettings(
    val drawMode: DrawMode = DrawMode.ONE,
    val tapToMove: Boolean = true,
    val fourColor: Boolean = false,
    val leftHanded: Boolean = false,
)

/** [counted] is true once this game has been added to "played". */
@Serializable
data class SavedGame(val session: Session, val counted: Boolean)

data class KlondikeUiState(
    val session: Session,
    val settings: KlondikeSettings,
    val hint: Move? = null,
    val autoFinishing: Boolean = false,
) {
    val state: GameState get() = session.state
}

class KlondikeViewModel(
    private val services: GameServices,
    private val newSeed: () -> Long = { Random.nextLong() },
) : ViewModel() {
    private val _ui = MutableStateFlow<KlondikeUiState?>(null)
    val ui: StateFlow<KlondikeUiState?> = _ui.asStateFlow()

    val stats: StateFlow<GameStats> = services.stats.observe(KLONDIKE_ID)
        .stateIn(viewModelScope, SharingStarted.Eagerly, GameStats())

    private var counted = false
    private var visible = false
    private var timerJob: Job? = null
    private var saveJob: Job? = null

    init {
        viewModelScope.launch {
            val settings = services.store.readJson(KLONDIKE_SETTINGS_KEY, KlondikeSettings())
            val saved = services.store.readJson<SavedGame?>(saveKey(KLONDIKE_ID), null)
            counted = saved?.counted ?: false
            _ui.value = KlondikeUiState(saved?.session ?: Session(GameState.deal(newSeed(), settings.drawMode)), settings)
            if (saved == null) services.feedback.play(FeedbackEvent.Deal)
            updateTimer()
        }
    }

    private val ready: KlondikeUiState? get() = _ui.value?.takeIf { !it.autoFinishing }

    fun onDraw() {
        if (play(Move.Draw)) services.feedback.play(FeedbackEvent.Draw)
    }

    fun onTapCard(from: Pile, count: Int) {
        val ui = ready ?: return
        if (!ui.settings.tapToMove) return
        val move = ui.state.bestMoveFor(from, count)
        if (move == null) services.feedback.play(FeedbackEvent.Invalid) else playTransfer(move)
    }

    fun onPickup() {
        if (ready != null) services.feedback.play(FeedbackEvent.Pickup)
    }

    /** Tries each candidate in order; returns whether the cards moved. */
    fun onDrop(from: Pile, count: Int, candidates: List<Pile>): Boolean {
        if (ready == null || candidates.isEmpty()) return false
        val moved = candidates.any { to -> playTransfer(Move.Transfer(from, to, count)) }
        if (!moved) services.feedback.play(FeedbackEvent.Invalid)
        return moved
    }

    fun onUndo() {
        val ui = ready ?: return
        if (ui.state.isWon) return
        val previous = ui.session.undo() ?: return
        commit(ui.copy(session = previous, hint = null))
        services.feedback.play(FeedbackEvent.Place)
    }

    fun onHint() {
        val ui = ready ?: return
        _ui.value = ui.copy(hint = ui.state.hint())
    }

    fun onNewGame() {
        val ui = ready ?: return
        val state = ui.state
        if (state.moves > 0 && !state.isWon) {
            viewModelScope.launch { services.stats.update(KLONDIKE_ID) { it.recordAbandon() } }
        }
        counted = false
        commit(ui.copy(session = Session(GameState.deal(newSeed(), ui.settings.drawMode)), hint = null))
        services.feedback.play(FeedbackEvent.Deal)
        updateTimer()
    }

    fun onAutoFinish() {
        val ui = ready ?: return
        val moves = ui.state.autoCompleteMoves()
        if (moves.isEmpty()) return
        _ui.value = ui.copy(autoFinishing = true, hint = null)
        viewModelScope.launch {
            for (m in moves) {
                applyMove(m)
                delay(AUTO_FINISH_STEP_MS)
            }
            _ui.update { it?.copy(autoFinishing = false) }
        }
    }

    fun updateSettings(f: (KlondikeSettings) -> KlondikeSettings) {
        val ui = _ui.value ?: return
        val settings = f(ui.settings)
        _ui.value = ui.copy(settings = settings)
        viewModelScope.launch { services.store.writeJson(KLONDIKE_SETTINGS_KEY, settings) }
    }

    fun setVisible(visible: Boolean) {
        this.visible = visible
        updateTimer()
        if (!visible) {
            saveJob?.cancel()
            viewModelScope.launch { save() }
        }
    }

    private fun play(move: Move): Boolean = ready != null && applyMove(move)

    private fun playTransfer(move: Move.Transfer): Boolean = play(move)

    /** Applies [move] regardless of auto-finish; plays feedback and handles stats and win. */
    private fun applyMove(move: Move): Boolean {
        val ui = _ui.value ?: return false
        val next = ui.session.play(move) ?: return false
        commit(ui.copy(session = next, hint = null))
        if (move is Move.Transfer) {
            services.feedback.play(if (move.to is Pile.Foundation) FeedbackEvent.Foundation else FeedbackEvent.Place)
        }
        if (!counted) {
            counted = true
            viewModelScope.launch { services.stats.update(KLONDIKE_ID) { it.recordStart() } }
            updateTimer()
        }
        if (next.state.isWon) onWin(next.state)
        return true
    }

    private fun onWin(state: GameState) {
        services.feedback.play(FeedbackEvent.Win)
        updateTimer()
        viewModelScope.launch { services.stats.update(KLONDIKE_ID) { it.recordWin(state.elapsedMs, state.score) } }
    }

    private fun commit(ui: KlondikeUiState) {
        _ui.value = ui
        saveJob?.cancel()
        saveJob = viewModelScope.launch {
            delay(SAVE_DEBOUNCE_MS)
            save()
        }
    }

    private suspend fun save() {
        val ui = _ui.value ?: return
        val keep = ui.state.moves > 0 && !ui.state.isWon
        services.store.writeJson(saveKey(KLONDIKE_ID), if (keep) SavedGame(ui.session, counted) else null)
    }

    private fun updateTimer() {
        timerJob?.cancel()
        val state = _ui.value?.state ?: return
        if (!visible || state.moves == 0 || state.isWon) return
        timerJob = viewModelScope.launch {
            while (true) {
                delay(1_000)
                _ui.update { it?.copy(session = it.session.tick(1_000)) }
            }
        }
    }
}
```

Note: `onDraw` plays `Draw` feedback only; `applyMove` plays Place/Foundation only for transfers, so a draw gets one sound.

```kotlin
@Composable
internal fun Table(ui: KlondikeUiState, viewModel: KlondikeViewModel, modifier: Modifier = Modifier) {
    val state = ui.state
    val style = remember(ui.settings.fourColor) { CardStyle(fourColor = ui.settings.fourColor) }
    val reducedMotion = rememberReducedMotion()
    BoxWithConstraints(modifier.fillMaxSize()) {
        val density = LocalDensity.current
        val width = constraints.maxWidth.toFloat()
        val height = constraints.maxHeight.toFloat()
        val gap = with(density) { 6.dp.toPx() }
        val layout = remember(state, width, height, ui.settings.leftHanded) {
            computeLayout(state, width, height, gap, ui.settings.leftHanded)
        }
        val cardSize = with(density) { DpSize(layout.cardSize.width.toDp(), layout.cardSize.height.toDp()) }
        var drag by remember { mutableStateOf<Drag?>(null) }
        val currentLayout by rememberUpdatedState(layout)
        val currentUi by rememberUpdatedState(ui)

        fun Rect.dp() = with(density) { Modifier.offset(left.toDp(), top.toDp()).size(width.toDp(), height.toDp()) }

        // Empty pile markers.
        CardSlot(if (state.waste.isNotEmpty()) "↻" else null, KlondikeColors.ink, layout.stock.dp().testTag("stock"))
        layout.piles.forEach { (pile, rect) ->
            when (pile) {
                is Pile.Foundation -> CardSlot(pile.suit.symbol, KlondikeColors.ink, rect.dp())
                is Pile.Tableau -> CardSlot("K", KlondikeColors.ink, Rect(rect.topLeft + Offset(gap / 2, 0f), layout.cardSize).dp())
                Pile.Waste -> Unit
            }
        }

        if (state.isWon) {
            WinCascade(layout, style, height)
        } else {
            val hinted = remember(ui.hint, state) { hintedCards(ui.hint, ui) }
            layout.cards.forEach { p ->
                key(p.card) {
                    val dragOffset = drag?.takeIf { p.card in it.cards }?.offset
                    MovingCard(
                        placement = p,
                        spawn = layout.stock.topLeft,
                        fresh = state.moves == 0,
                        seed = state.seed,
                        dragOffset = dragOffset,
                        reducedMotion = reducedMotion,
                    ) { mod ->
                        PlayingCard(
                            p.card,
                            p.faceUp,
                            style,
                            mod.size(cardSize)
                                .testTag("card-${p.card}")
                                .then(if (p.card in hinted) Modifier.hintGlow(cardSize.width) else Modifier),
                        )
                    }
                }
            }
            ui.hint?.let { HintTarget(it, layout) { rect -> rect.dp() } }
        }

        // One gesture layer above everything.
        Box(
            Modifier
                .fillMaxSize()
                .zIndex(10_000f)
                .pointerInput(Unit) {
                    detectTapGestures { pos ->
                        val l = currentLayout
                        if (l.stock.contains(pos)) {
                            viewModel.onDraw()
                            return@detectTapGestures
                        }
                        val p = l.cardAt(pos) ?: return@detectTapGestures
                        val pile = p.pile ?: return@detectTapGestures
                        if (!p.faceUp) return@detectTapGestures
                        val count = pickCount(currentUi, pile, p.index) ?: return@detectTapGestures
                        viewModel.onTapCard(pile, count)
                    }
                }
                .pointerInput(Unit) {
                    detectDragGestures(
                        onDragStart = { pos ->
                            val l = currentLayout
                            val p = l.cardAt(pos)?.takeIf { it.faceUp } ?: return@detectDragGestures
                            val pile = p.pile ?: return@detectDragGestures
                            val count = pickCount(currentUi, pile, p.index) ?: return@detectDragGestures
                            val cards = currentUi.state.pickUp(pile, count) ?: return@detectDragGestures
                            drag = Drag(pile, count, cards.toSet(), cards.first(), Offset.Zero)
                            viewModel.onPickup()
                        },
                        onDrag = { change, delta ->
                            val d = drag ?: return@detectDragGestures
                            change.consume()
                            drag = d.copy(offset = d.offset + delta)

                        onDragEnd = {

                                viewModel.onDrop(d.from, d.count, l.dropCandidates(rect).filter { it != d.from })
                            }
                            drag = null
                        },
                        onDragCancel = { drag = null },
                    )
                },
        )
    }

/** How many cards a touch at [index] of [pile] picks up, or null if that card cannot be picked up. */
private fun pickCount(ui: KlondikeUiState, pile: Pile, index: Int): Int? = when (pile) {
    is Pile.Tableau -> ui.state.tableau[pile.index].size - index
    Pile.Waste -> 1.takeIf { index == ui.state.waste.lastIndex }
    is Pile.Foundation -> 1.takeIf { index == ui.state.foundation(pile.suit).lastIndex }
}

private fun hintedCards(hint: Move?, ui: KlondikeUiState): Set<Card> = when (hint) {
    is Move.Transfer -> ui.state.pickUp(hint.from, hint.count)?.toSet().orEmpty()
    else -> emptySet()
}

/** Animates a card toward its slot; snaps while dragged; staggers the opening deal. */
@Composable
private fun MovingCard(
    placement: CardPlacement,
    spawn: Offset,
    fresh: Boolean,
    seed: Long,
    dragOffset: Offset?,
    reducedMotion: Boolean,
    content: @Composable (Modifier) -> Unit,
) {
    val target = placement.topLeft + (dragOffset ?: Offset.Zero)
    val anim = remember { Animatable(if (fresh && !reducedMotion) spawn else target, Offset.VectorConverter) }
    val dealing = remember(seed) { mutableStateOf(fresh) }
    LaunchedEffect(target, dragOffset != null) {
        when {
            dragOffset != null || reducedMotion -> anim.snapTo(target)
            dealing.value -> {
                delay(placement.z * 14L)
                dealing.value = false
                anim.animateTo(target, Motion.card())
            }
            else -> anim.animateTo(target, Motion.card())
        }
    }
    val lifted = dragOffset != null || anim.isRunning
    content(
        Modifier
            .zIndex(placement.z + if (lifted) 1_000f else 0f)
            .offset { IntOffset(anim.value.x.roundToInt(), anim.value.y.roundToInt()) }
            .shadow(if (dragOffset != null) 10.dp else 1.dp, RoundedCornerShape(6.dp), clip = false),
    )
}

private fun Modifier.hintGlow(width: androidx.compose.ui.unit.Dp): Modifier = this.then(
    Modifier.border(2.dp, KlondikeColors.accent, RoundedCornerShape(width * 0.09f)),
)

@Composable
private fun HintTarget(hint: Move, layout: TableLayout, place: (Rect) -> Modifier) {
    val rect = when (hint) {
        Move.Draw -> layout.stock
        is Move.Transfer -> {
            val area = layout.piles[hint.to] ?: return
            if (hint.to is Pile.Tableau) {
                val top = layout.cards.filter { it.pile == hint.to }.maxByOrNull { it.index }?.topLeft
                    ?: Offset(area.left + (area.width - layout.cardSize.width) / 2, area.top)
                Rect(top, layout.cardSize)
            } else area
        }
    }
    val pulse by rememberInfiniteTransition(label = "hint").animateFloat(
        initialValue = 0.35f,
        targetValue = 1f,
        animationSpec = infiniteRepeatable(tween(700), RepeatMode.Reverse),
        label = "hintPulse",
    )
    Box(
        place(rect)
            .zIndex(5_000f)
            .border(3.dp, KlondikeColors.accent.copy(alpha = pulse), RoundedCornerShape(8.dp)),
```

```kotlin
import kotlin.math.roundToInt

/** Foundation cards drift down off the table one by one, kings first. */
@Composable
internal fun WinCascade(layout: TableLayout, style: CardStyle, height: Float) {
    val density = LocalDensity.current
    val size = with(density) { DpSize(layout.cardSize.width.toDp(), layout.cardSize.height.toDp()) }
    val cards = remember(layout) {
        layout.cards.filter { it.pile is Pile.Foundation }.sortedWith(compareByDescending<CardPlacement> { it.index }.thenBy { it.card.suit })
    }
    cards.forEachIndexed { i, p ->
        key(p.card) {
            val progress = remember { Animatable(0f) }
            val rnd = remember { Random(p.card.hashCode()) }
            val drift = remember { (rnd.nextFloat() - 0.5f) * layout.cardSize.width * 4f }
            val spin = remember { (rnd.nextFloat() - 0.5f) * 50f }
            LaunchedEffect(Unit) {
                delay(i * 45L)
                progress.animateTo(1f, tween(1500, easing = FastOutLinearInEasing))
            }
            val fall = height + layout.cardSize.height - p.topLeft.y
            PlayingCard(
                p.card,
                true,
                style,
                Modifier
                    .zIndex(1_000f - i)
                    .offset {
                        val t = progress.value
                        IntOffset((p.topLeft.x + drift * t).roundToInt(), (p.topLeft.y + fall * t * t).roundToInt())
                    }
                    .size(size)
                    .graphicsLayer { rotationZ = spin * progress.value },
            )
        }
    }
}
```

```kotlin
@Composable
private fun StatsCard(game: GameEntry, s: GameStats, onReset: suspend () -> Unit) {
    val scope = rememberCoroutineScope()
    var confirm by remember { mutableStateOf(false) }
    Card(
        shape = RoundedCornerShape(28.dp),
        colors = CardDefaults.cardColors(containerColor = game.palette.background, contentColor = game.palette.onBackground),
    ) {
        Column(Modifier.fillMaxWidth().padding(24.dp)) {
            Text(game.title, style = MaterialTheme.typography.titleLarge)
            Spacer(Modifier.height(16.dp))
            StatRow("Played" to s.played.toString(), "Won" to s.won.toString(), "Win rate" to "${(s.winRate * 100).toInt()}%")
            Spacer(Modifier.height(12.dp))
            StatRow(
                "Best time" to (s.bestTimeMs?.let(::formatTime) ?: "-"),
                "Best score" to (s.bestScore?.toString() ?: "-"),
                "Streak" to "${s.currentStreak} / ${s.bestStreak}",
            )
            Spacer(Modifier.height(8.dp))
            TextButton(onClick = { confirm = true }) { Text("Reset", color = game.palette.onBackground.copy(alpha = 0.7f)) }
        }
    }
    if (confirm) {
        AlertDialog(
            onDismissRequest = { confirm = false },
            title = { Text("Reset ${game.title} statistics?") },
            confirmButton = { TextButton(onClick = { confirm = false; scope.launch { onReset() } }) { Text("Reset") } },
            dismissButton = { TextButton(onClick = { confirm = false }) { Text("Cancel") } },
        )
    }
}

@Composable
private fun StatRow(vararg items: Pair<String, String>) {
    Row(Modifier.fillMaxWidth()) {
        items.forEach { (label, value) ->
            Column(Modifier.weight(1f)) {
                Text(value, style = MaterialTheme.typography.titleLarge)
                Text(label, style = MaterialTheme.typography.labelMedium, color = MaterialTheme.typography.labelMedium.color)
            }
        }
    }
}

private fun formatTime(ms: Long): String {
    val total = ms / 1000
    return "%d:%02d".format(total / 60, total % 60)
}
```

```kotlin
import java.util.Properties

val keystoreProps = Properties().apply {
    val f = rootProject.file("keystore.properties")
```

Inside `android { }`:
```kotlin
    signingConfigs {
        if (keystoreProps.isNotEmpty()) {
            create("release") {
                storeFile = file(keystoreProps.getProperty("storeFile"))

                keyAlias = keystoreProps.getProperty("keyAlias")
                keyPassword = keystoreProps.getProperty("keyPassword")
            }
        }
    }
```
And in `buildTypes.release`: `signingConfig = signingConfigs.findByName("release")`.

- [ ] **Step 2: Create a local keystore**

```bash
mkdir -p ~/Android/keystores
PASS=$(openssl rand -base64 24 | tr -d '/+=')
~/Android/jdk/bin/keytool -genkeypair -v -keystore ~/Android/keystores/tabletop-release.jks -alias tabletop \
  -keyalg RSA -keysize 4096 -validity 10000 -storepass "$PASS" -keypass "$PASS" -dname "CN=Tabletop"
printf "storeFile=%s\nstorePassword=%s\nkeyAlias=tabletop\nkeyPassword=%s\n" "$HOME/Android/keystores/tabletop-release.jks" "$PASS" "$PASS" > keystore.properties
```
The user must back up the keystore and password; losing them means future updates cannot install over existing ones.
